# Make the Judge Laugh in One Line

One funny line, 200 characters or fewer, for the [make.fun bounty](https://make.fun/bounty/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21).

> My grandfather's gravestone has a QR code now — scan it and it plays his voicemail, which is just him saying 'call your mother' from beyond the grave.

## How it works

`main.ts` writes the line to `/output/entry.txt`. Nothing else to build, install, or upload.

## QA

- Run `main.ts` twice: output byte-identical.
- 150 characters (limit 200), 1 line, no trailing newline, valid UTF-8.
- SHA-256 of output: `f102d304cd41ebe88ec1ae5bdc4ba5d26793e452c68a27e78d877894d0d116b5`
- No personal details.
